# User Stories

## User Story 1
- **As a** user who wants to give away items,
- **I want to** list a household item with title, description, and category,
- **So that** someone else can reuse it instead of throwing it away.

## User Story 2
- **As a** user looking for free items,
- **I want to** search and filter available items by category and condition,
- **So that** I can easily find what I need locally.
